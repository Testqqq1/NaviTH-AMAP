# NaviTH visual redesign (Android native)

**Design tokens** (native Android): primary #087F77, accent #DDF3F0, canvas #F7F9FA, text #172B32, border #B8CDD0. 16sp body, 14sp explanatory copy, 20–24sp headers, 48dp minimum touch targets; 16dp control rounding and 20dp card rounding.

Priority: map first, search second, contextual journey panel third. Labels and routes remain vendor-supplied; arbitrary per-category label filtering and native color saturation cannot be guaranteed without an AMAP Custom Map Style.

UI and AMap Navigation/Android Auto remain separate. Never display a “Start navigation” primary action in a Maps-only build. Debug/experimental APKs are not approved for driving or production use.
